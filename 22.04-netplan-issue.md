# Ubuntu 22.04 Netplan Configuration Guide

This guide helps you disable cloud-init's network management on Ubuntu 22.04 to resolve netplan issues.

## Problem
Cloud-init may interfere with netplan network configuration on Ubuntu 22.04, causing network management conflicts.

## Solution

### Step 1: Create Configuration File
Create a new configuration file to disable cloud-init's network management:

```bash
sudo nano /etc/cloud/cloud.cfg.d/99-disable-network-config.cfg
```

### Step 2: Add Configuration Content
Add the following content to the file:

```yaml
network: {config: disabled}
```

### Step 3: Save and Exit
- Press `Ctrl + X` to exit nano
- Press `Y` to confirm saving
- Press `Enter` to confirm the filename

### Step 4: Apply Network Configuration
Apply the netplan configuration to activate your changes:

```bash
sudo nano /etc/netplan/50-cloud-init.aml
```

```bash
network:
    ethernets:
        enp6s18:
            dhcp4: false
            addresses:
                - 192.168.1.100/24
            routes:
                - to: default
                  via: 192.168.1.1
            nameservers:
                addresses:
                    - 8.8.8.8
                    - 8.8.4.4
    version: 2
```

```bash
sudo netplan apply
```

## What This Does
- **Disables cloud-init network management**: Prevents cloud-init from overriding your manual network configuration
- **Enables full netplan control**: Allows netplan to manage network settings without interference
- **Resolves configuration conflicts**: Eliminates competing network management systems



## 🔄 DHCP Lease Management on Ubuntu 22.04 (CLI)

Use `dhclient` to release and renew DHCP leases safely.

### 🧼 Release DHCP Lease
```bash
sudo dhclient -r
```
- Sends a DHCP release message to the server.
- Drops the current lease and frees the IP.

### 🔄 Renew DHCP Lease
```bash
sudo dhclient
```
- Requests a new IP address from the DHCP server.

To target a specific interface:
```bash
sudo dhclient -v enp3s0
```
- Replace `enp3s0` with your actual interface name.
- `-v` enables verbose output for debugging.

### 🧠 Check Interface Name
```bash
ip link show
```
- Lists all network interfaces.
- Look for names like `eth0`, `enpXsY`, or `wlan0`.

### ✅ Optional: Dry-Run Safety Script
```bash
#!/bin/bash
iface="enp3s0"

if ip link show "$iface" | grep -q "state UP"; then
  echo "Interface $iface is up. Renewing DHCP lease..."
  sudo dhclient -v "$iface"
else
  echo "Interface $iface is down. Skipping DHCP renewal."
fi
```
- Replace `enp3s0` with your interface.
- Ensures renewal only if the interface is active.
```
